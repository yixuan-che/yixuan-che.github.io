# Yixuan Che's Portfolio
Yixuan Che's brand-new homepage, built with the Nikola Tesla Portfolio template of course Astro 5.7, React 19 and TailwindCSS 4

## Getting Started
Clone Repository
```sh
git clone https://github.com/yixuan-che/yixuan-che.github.io.git
```

Install Dependencies
```sh
pnpm install
```

Development
```sh
pnpm run dev
```

Build
```sh
pnpm run build
```

Preview
```sh
pnpm run preview
```

## Project Structure

Inside of your Astro project, you'll see the following folders and files:

```text
/
├── public/
│   └── favicon.svg
├── src/
│   ├── actions/
│   │   └── # Astro server actions
│   ├── assets/
│   │   └── # Images that are transformed, optimized and bundled by Astro 
│   ├── components/
│   │   └── # Astro and React components
│   ├── layouts/
│   │   └── InfoLayout.astro
│   │   └── RootLayout.astro
│   └── pages/
│   │   └── bio.astro
│   │   └── contact.astro
│   │   └── index.astro
│   │   └── publications.astro
│   │   └── research.astro
│   └── styles/
│   │   └── global.css
└── .gitignore
└── astro.config.mjs
└── package.json
└── tsconfig.json
```

## Deployment
The site is configured for deployment on Vercel, but with slight modifications it can be deployed to any hosting service.
